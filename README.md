# CSE479_Gomoku_Game
A Gomoku game built with HTML, CSS, and JavaScript. This 2-player strategy game features a retro arcade design, interactive grid, dynamic scoreboard, timer, and a Play/Restart button. Players take turns to align five pieces in a row while enjoying a neon-themed, pixelated interface.

The game includes:
A dynamic scoreboard that tracks wins for both players.
A timer that tracks the elapsed time during gameplay.
A Play/Restart button that starts and resets the game.
Interactive grid cells with color-changing hover effects based on the active player.

This project aims to provide a fun, interactive experience with an arcade-inspired interface, showcasing basic game development skills.
